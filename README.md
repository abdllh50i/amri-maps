# amri-maps

The offline map pack of AMRI OS 2.0 for Saudi Arabia: base map, routing, places and map fonts, in chunks with SHA-256 hashes. The unit downloads it from this repository's releases, or from a USB stick.

حزمة خريطة السعودية لنظام AMRI OS 2.0: الخريطة والطرق والأماكن وخطوط الخريطة. الشاشة تنزلها من إصدارات هذا المستودع، أو من فلاش USB.

**How it is made:** `tools/mapbuild/` of https://github.com/abdllh50i/aura-launcher (published with AMRI OS 2.0).

Nothing here comes from Google.
